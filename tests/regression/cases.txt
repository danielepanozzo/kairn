# Kairn's regression cases: request lines of the oracle's protocol (docs/developer/architecture.md,
# "The line protocol"), operands only, each under a comment that says where it came from and what it
# once showed. The quick tier's test regression.cases (tests/regression/run.py) runs every line of
# binary64 and binary32 through every compiled runner the build has and through every form of the
# public interface that calls its kernel, and every line, toy formats included, through the
# generator's interpreter; the oracle judges each result against gen/claims.json.
#
# The rule for adding a line. A containment failure or a bound violation, wherever it is found (a
# cross-check, the brute-force tier, kairn-oracle search, a user), is shrunk with
#   python3 oracle/kairn-oracle shrink 'LINE' --runner RUNNER
# and the shrunk line goes into the first section, under a comment that names where it was found
# (the test or the run, and the runner), the entry it failed, and the class of the fault:
#   statement  the claim, or the theorem under it, says more than holds;
#   generator  the generated code differs from the kernel's description (the interpreter passes);
#   code       the kernel's description, or the code of the public interface around it, is wrong;
#   compiler   a compiler, or one of its settings, changes the arithmetic (others pass);
#   hardware   one processor gives other results for the same program.
# A line stays after the fault is fixed: it keeps the fault from coming back. A case the protocol
# cannot carry gets a test of its own, named in a comment here. The lines of the later sections only
# came close to a claim; one is replaced when a closer case of the same claim is found.
#
# Not here, each with a test of its own:
# - the product of the program fused into a kernel (x + a * b, deviation 1b of docs/developer/
#   design/phase0/decisions.md): the protocol gives the runner the rounded product, so a line
#   cannot carry it; api.boundary.* (tests/api/boundary.cpp) computes 200 000 such sums from a
#   fixed seed under every contraction setting;
# - the comparisons with a NaN that one compiler's constant evaluator took as true (commit
#   2c6cf88): constant evaluation, in NAN_CE_CASES of gen/tests/test_cxx.py and in
#   tests/api/constexpr.cpp;
# - the operands of SPECIAL_CASES in gen/tests/test_cxx.py marked "outside", which are outside
#   their kernel's domain (the oracle would call them invalid): bit identity with the interpreter
#   is required on them, and only there.
