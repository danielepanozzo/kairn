# Kairn

Rigorous floating-point expansions ("k-numbers") with interval and ball arithmetic, in
header-only C++20. Every error bound is meant to carry a machine-checked proof, and the
shipped code is generated from the same source the proofs are about.

**Status: Phase 0 (specification and feasibility). There is no library yet.**

The original brief is in [`docs/developer/design/brief.md`](docs/developer/design/brief.md).
